# Getting Started

**Compatibility:** EasyUI 0.2.0+. No prerequisite sample imports.

Open `GettingStarted.unity`, then Play. I / Start opens inventory. Select Settings → Apply settings. Arrows / D-pad / left stick navigate, Enter / A confirms, Esc / B goes back. The parent's selection and gameplay request survive a child closing.

Tab / RB toggles radial; hold R / LB and release to select. Mouse or stick chooses; click / Enter / A confirms; center and disabled items select nothing. Space increments the gameplay counter only after all blocking menus close and the closing input is released.

The scene, window prefabs and Window Definition assets are editable. Tools → EasyUI → Create Getting Started Scene creates another copy under Assets/EasyUI Example without replacing your current scene.
